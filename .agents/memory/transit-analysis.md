---
name: Transit analysis boundaries
description: Approved approach for ranked daily transit context and duration reliability.
---

Keep transit analysis on the existing Astronomy Engine. Applying/separating status must come from observed positions on both sides of the current time, not from orb size alone. Use transparent lexicographic ranking rather than an undocumented weighted score. Approximate durations must be sampled from actual positions; when a bounded search does not observe an exit, report a lower bound instead of inventing a precise end date. Unknown birth times remain limited-confidence.

For daily Cosmos copy, name the current transit and the natal placement it touches, then explain their themes in plain language. Mention a secondary aspect only when it shares a theme with the main one. Use a mood only when it was selected for the current device-local day. Unknown-time readings must not imply house or exact-angle precision.

**Why:** the approved technical specification explicitly forbids replacing the ephemeris, arbitrary ranking weights, orb-only motion guesses, unsupported duration claims, and stale or overconfident personal readings.

**How to apply:** later reading and crystal phases should consume the structured transit analysis, preserve its uncertainty, avoid presenting sampled estimates as predictions, and keep the seven localized versions consistent in meaning.
