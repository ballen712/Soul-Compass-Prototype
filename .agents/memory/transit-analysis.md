name: Transit analysis boundaries
description: Approved approach for ranked daily transit context and duration reliability.
---

Keep transit analysis on the existing Astronomy Engine. Applying/separating status must come from observed positions on both sides of the current time, not from orb size alone. For daily crystals, use the approved deterministic weights: main transit 35%, the eight stable natal companions 25%, current-day mood 20%, related supporting aspects 10%, and saved intentions 10%. Assign duplicate theme tags to the highest-priority factor only; calculate hidden/owned availability separately from suitability. Approximate transit durations must be sampled from actual positions; when a bounded search does not observe an exit, report a lower bound instead of inventing a precise end date. Unknown birth times remain limited-confidence.

For daily Cosmos copy, name the current transit and the natal placement it touches, then explain their themes in plain language. Mention a secondary aspect only when it shares a theme with the main one. Use a mood only when it was selected for the current device-local day. Unknown-time readings must not imply house or exact-angle precision.

**Why:** the approved specification permits these explicit weights but requires their formula to be documented and non-overlapping; hidden stones and collection ownership must not alter the underlying suitability score.

**How to apply:** later reading and crystal changes should consume structured transit analysis, preserve its uncertainty, keep mood valid only for the device-local day, and retain separate availability and presentation-diversity steps. Keep the formula explanation consistent in all seven languages.
